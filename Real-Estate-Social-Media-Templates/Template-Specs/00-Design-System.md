# Real Estate Social Media Templates - Master Design System

## Brand Identity

### Color Palette
| Name | Hex | Usage |
|------|-----|-------|
| Navy | #1B2A4A | Primary backgrounds, text |
| Gold | #C9A84C | Accents, borders, CTAs |
| Crisp White | #FFFFFF | Text on dark, backgrounds |
| Light Navy | #2D4066 | Secondary backgrounds |
| Soft Gold | #E8D5A3 | Subtle accents, dividers |
| Off-White | #F8F6F1 | Light backgrounds |
| Charcoal | #333333 | Body text on light bg |

### Typography
| Element | Font | Weight | Size (Square) | Size (Story) |
|---------|------|--------|---------------|--------------|
| Main Heading | Playfair Display | Bold | 60-80px | 72-96px |
| Subheading | Playfair Display | Regular | 36-48px | 42-56px |
| Body Text | Open Sans | Regular | 24-32px | 28-36px |
| CTA / Button | Open Sans | Semi-Bold | 28-36px | 32-40px |
| Small Text / Tag | Open Sans | Light | 18-24px | 22-28px |

### Canvas Sizes
| Format | Dimensions | Platform |
|--------|-----------|----------|
| Square Post | 1080 x 1080 px | Instagram Feed, Facebook |
| Story / Reel Cover | 1080 x 1920 px | Instagram Stories, Reels, TikTok |

### Graphic Elements
- Minimalist house outlines (thin line weight)
- Star ratings (5-star gold icons)
- "SOLD" ribbons (diagonal banner)
- "JUST LISTED" badges (rectangular)
- Gold line dividers
- Subtle drop shadows on photo frames
- Rounded corner photo masks (16px radius)
